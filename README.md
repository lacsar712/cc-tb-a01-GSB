# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

拼配须先挂母叶比例尺：审评员在比例尺页为批次登记若干母叶名与占比，全部占比相加必须正好 100 才存得进去。比例尺生效后该批才能交审评；未挂比例尺的批次直接拒交并提示缺比例尺。观察员只能翻看已生效的比例尺，不能改占比。顶栏「比例尺」进入独立比例尺页，可按批次查当前占比表。改占比只影响后续提交，旧审评行的加权分不重算。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 顶栏点「比例尺」进独立比例尺页，给春芽登记龙井 45、碧螺春 55（合计 100）保存生效；合计不是 100 存不进去。
3. 回到总表给春芽交香气 9、滋味 8、汤色 6，新行出现在表头（加权 7.9 通过），页面不整页刷新；未挂比例尺的批次提交会被拒并提示缺比例尺。
4. 改春芽占比后，旧审评行的加权分保持 7.9 不变；删掉春芽的比例尺再交同批必须失败。
5. observer 登录后没有提交表单，只能翻看已生效的比例尺，不能登记、改占比或删除。
