# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

拼配前必须先挂**母叶比例尺**：审评员为批次登记若干母叶名与占比，占比合计必须**正好为 100**，否则不予生效。比例尺生效后该批交审评才放行；未挂比例尺的批次直接拒交并提示缺比例尺。观察员只能翻阅已生效的比例尺，不能改占比。改占比不会重算已交审评行的加权分（分数在交评时固化）。

这是制茶审评，不是菜谱，也不是饮食记录。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过，顶栏有「母叶比例尺」入口。
2. 未挂比例尺的批次交审评被拒，提示缺母叶比例尺。
3. 在比例尺页给「春芽」登记龙井 45、碧螺春 55（合计非 100 存不进去），生效后回总表递交香气 9、滋味 8、汤色 6，新行通过、加权分 7.9。
4. 把春芽占比改成 50/50，总表旧审评行加权分仍是 7.9，不跟着重算。
5. 删掉春芽的比例尺后再交同批必须失败；重新挂回才可交。
6. observer 登录后比例尺页没有登记/修改/删除入口，写接口一律 403，但可按批次查当前占比表。
